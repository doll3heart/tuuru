# Newly Added Feature Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refine the recently added author notes, ordinary interaction, hidden-node condition, and interactive-picture surfaces into one coherent editor experience without changing their reading semantics.

**Architecture:** Keep work data, branching, reader runtime, and interactive-scene behavior unchanged. Expand only the private local author-notes record with a versioned migration, then improve author-facing markup, copy, state summaries, and responsive styling using the existing editor components and color tokens.

**Tech Stack:** Vanilla JavaScript modules, semantic HTML generated by JavaScript, CSS custom properties, Node test runner, JSDOM.

## Global Constraints

- Preserve all existing reader behavior and work export semantics.
- Private author notes remain local-only and absent from JSON/PNG work exports.
- Do not change hidden-node AND-of-OR evaluation, stable choice IDs, or route memory.
- Do not change interactive-picture scene, hotspot, camera, media, or dialogue runtime behavior.
- Reuse existing Tuuru color, typography, button, focus, and responsive conventions.
- Do not stage, commit, or overwrite unrelated dirty-worktree changes.
